# LeadOps Admin Dashboard

Next.js admin dashboard for the AI real-estate lead qualification agent.

## What it does

- Reads leads from PostgreSQL (`agency` database, `leads` table)
- Shows pipeline stats and stage distribution
- Shows upcoming meetings from `meeting_time`
- Search and filter leads
- Open a lead details panel
- Edit qualification fields and meeting time
- Auto-refreshes every 15 seconds

## Database connection

Create `.env.local` in the project root:

```env
PGHOST=localhost
PGPORT=5432
PGDATABASE=agency
PGUSER=postgres
PGPASSWORD=YOUR_POSTGRES_PASSWORD
```

Or use one connection string:

```env
DATABASE_URL=postgresql://postgres:YOUR_POSTGRES_PASSWORD@localhost:5432/agency
```

The dashboard talks to PostgreSQL through Next.js API routes. The database credentials stay on the server and are never exposed to the browser.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Required table

```sql
CREATE TABLE leads (
    id SERIAL PRIMARY KEY,
    contact_id TEXT UNIQUE NOT NULL,
    name TEXT,
    budget TEXT,
    area TEXT,
    intent TEXT,
    timeline TEXT,
    stage TEXT DEFAULT 'new',
    qualified BOOLEAN DEFAULT NULL,
    meeting_time TIMESTAMP,
    last_message TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

## How the connection works

```text
Browser
   ↓
Next.js UI
   ↓
/api/leads and /api/stats
   ↓
pg Pool (server only)
   ↓
PostgreSQL → agency → leads
```
